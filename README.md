# 🐍 贪吃蛇大作战 v3.1

一款功能完整的贪吃蛇游戏，支持多种难度、皮肤主题和排行榜功能。

## 🎮 在线体验

访问 [https://qinjiang-lobster.github.io/snake-game](https://qinjiang-lobster.github.io/snake-game) 即可游玩！

## ✨ 功能特性

### 游戏玩法
- 🎯 经典贪吃蛇玩法，吃掉食物让蛇变长
- ⚡ 动态加速：每吃5个食物速度提升
- 📱 完美支持手机和电脑

### 难度选择
- 🟢 **简单模式**：基础速度150ms，适合新手
- 🟡 **普通模式**：基础速度100ms，标准挑战
- 🔴 **困难模式**：基础速度60ms，高手挑战

### 皮肤主题
- 🟢 **经典**：绿色蛇身 + 红色食物
- 🟣 **霓虹**：紫色蛇身 + 青色食物
- 🔥 **火焰**：橙色蛇身 + 黄色食物
- 🌊 **海洋**：蓝色蛇身 + 青色食物

### 控制方式
- **电脑**：方向键 ↑↓←→ 或 WASD
- **手机**：点击方向键或滑动屏幕
- **快捷操作**：空格键暂停/继续

### 排行榜
- 🏆 本地存储最高分和历史记录
- 📊 TOP 5 排行榜展示
- 🎉 新纪录提示

## 🔧 技术栈

- HTML5 Canvas 游戏渲染
- CSS3 渐变和动画效果
- Web Audio API 音效合成
- LocalStorage 数据持久化
